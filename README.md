# 🚀 KYU CONNECT - Modern Anonymous Dating & Chat Platform

## Project Overview
KYU CONNECT is a fully interactive, multi-page anonymous dating and chatting platform for students at Kirinyaga University and beyond. The application features a modern purple gradient design with smooth page navigation.

## 🚀 How to Use

### Opening the App
1. Open `index.html` in your web browser
2. You'll see the home page with discover profiles
3. Click any navigation icon to switch pages

### Navigation
- **Home** <i class="fas fa-home"></i> - Main discovery page
- **KYU** <i class="fas fa-graduation-cap"></i> - KYU students
- **Other Unis** <i class="fas fa-building"></i> - Other universities
- **Status** <i class="fas fa-pen"></i> - Social feed
- **Chat** <i class="fas fa-comments"></i> - Messages & chatting
- **AI** <i class="fas fa-robot"></i> - AI assistant
- **Profile** <i class="fas fa-user-circle"></i> - Your profile
- **Login/Signup** - Top right buttons

### Using Discovery Pages
1. View profile cards with user info
2. Click **Like** ❤️ to show interest
3. Click **Pass** ✖️ to skip
4. Card slides away with animation
5. Load more profiles by scrolling

### Using Chat
1. Click **Chat** in navigation
2. Select a conversation from the list
3. View message history
4. Type your message and press Enter or click Send
5. Switch between chats and groups freely

### Using AI Assistant
1. Click **AI** in navigation
2. Ask questions or click quick buttons
3. Get instant personalized responses
4. Try questions about:
   - Profile optimization
   - Conversation starters
   - Safety tips
   - Finding matches
